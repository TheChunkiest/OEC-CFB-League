# CFB 27 Dynasty Hub

Static league website. Every file lives at the top level (no folders), so it's easy to upload from a phone.

All teams, scores and news are SAMPLE data. Replace them.

## Publish on GitHub Pages
1. Create a public repo and upload all files in this folder.
2. Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.
3. Site appears at https://USERNAME.github.io/REPO/

## Weekly routine
1. Open yoursite/admin.html
2. Enter scores, advance the week, post news.
3. Tap the download buttons for changed files (e.g. games.json, league.json).
4. In your repo: Add file -> Upload files -> pick the downloaded files -> Commit. Same names replace the old ones.

Data files: teams, games, league, rankings, news, recruiting, awards, history (.json).
